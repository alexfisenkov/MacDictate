# Историческое лицензирование desktop

С 19.10.2026 macOS MacDictate бесплатен по решению владельца. Этот код сохранён
для истории и совместимости старых backend-клиентов; `build.sh` его не компилирует.
Не подключать его обратно к приложению: запись не зависит от подписки, даты,
сети, machine ID или license cache. Старые UserDefaults остаются нетронутыми.

`src/License/` содержит прежний клиент, состояние и кэш. `scripts/` — прежние
регрессионные проверки; два harness используют актуальные diagnostic types из
основного `src/Diagnostics/`. Эти проверки не являются QA бесплатной версии.
Текущая проверка: `bash scripts/test_free_desktop.sh` из корня macOS-репозитория.

Backend и старые платные установщики сохраняются отдельно до публичного выпуска
бесплатного приложения. Публичная доступность определяется release ledger.
