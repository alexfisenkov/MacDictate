# MacDictate для Windows

Бесплатная локальная диктовка для Windows x64. Приложение живёт в области уведомлений, записывает микрофон и распознаёт речь через bundled whisper.cpp на CPU. Лицензия, активация и сервер приложения не требуются.

Первая Windows-версия включает диктовку, выбор языка, настройку клавиш, установку модели и восстановление последнего текста. Автоматическое улучшение текста второй моделью пока доступно только в macOS-версии.

[Условия использования и политика конфиденциальности](https://alexfisenkov.github.io/MacDictate/legal.html). Их копии на русском и английском включены в папку `legal` внутри пакета.

## Установка и первая диктовка

1. Установите Windows x64 пакет из [GitHub Releases](https://github.com/alexfisenkov/MacDictate/releases) либо распакуйте portable ZIP целиком и запустите `MacDictate.exe`. .NET и Python отдельно не нужны. Windows-пакет пока без Authenticode-подписи; Windows может показать предупреждение о неизвестном издателе.
2. В открывшихся настройках нажмите **Download verified model**. Мультиязычная Whisper small занимает около 488 МБ; первая загрузка требует интернета. Загрузка проверяет закреплённый SHA-256 перед созданием файла. Уже скачанная проверенная модель используется повторно; другой файл с таким именем сохраняется, а загрузка просит сначала переместить его или выбрать существующую модель. Можно выбрать существующую совместимую Whisper `.bin` модель.
3. Разрешите доступ настольных приложений к микрофону в Windows 11: Settings → Privacy & security → Microphone; Windows 10: Settings → Privacy → Microphone. Выберите нужный микрофон по умолчанию в Sound.
4. Поставьте курсор в нужное текстовое поле. Дважды коротко нажмите **левый Alt**, чтобы начать запись; снова нажмите левый Alt дважды, чтобы остановить. Значок в трее показывает состояние; максимальная запись — две минуты. Не удерживайте Alt. Right Alt/AltGr, Alt+Tab, комбинации и автоповтор не запускают диктовку.
5. Дождитесь распознавания, сохраняя активное окно. Текст отправляется одним абзацем как Unicode-ввод Windows, без изменения буфера обмена и без нажатия Enter. Переносы сегментов распознавания превращаются в пробелы. Автоввод разрешён только при совпадении исходного поля ввода по Windows UI Automation и native focus HWND. Если поле/окно сменилось, исходное поле не удалось определить, зажаты модификаторы или Windows блокирует ввод в приложение с повышенными правами, используйте **Show / copy last dictation**. Успешная отправка ввода не подтверждает, что стороннее приложение приняло текст; некоторые приложения не поддерживают Unicode-ввод Windows. Ручное копирование остаётся доступным. Если ввод был остановлен после начала отправки, проверьте уже появившийся фрагмент перед ручной вставкой всего текста. Недоступный или медленный UI Automation provider даёт безопасный отказ от автоввода; ожидание ограничено 500 мс.

В настройках доступны языки `auto`, `ru`, `en` и альтернативные клавиши **Ctrl+Shift+Space** / **F8**. Альтернативы переключают запись повторным нажатием. Обычные нажатия клавиш не блокируются. Если Alt при остановке активировал системное меню того же окна, приложение закрывает только это активное меню через Esc перед распознаванием; при смене окна Esc не отправляется. Если это мешает, выберите альтернативу.

Окна настроек и последнего текста открываются из меню значка. **Cancel** отменяет запись или распознавание. **Clear saved dictation** очищает сохранённый текст.

## Локальные данные и ограничения

- Настройки, скачанная модель и последний текст: `%LOCALAPPDATA%\MacDictate`. Последний текст хранится до замены либо команды очистки. При явном ручном копировании буфер обмена Windows может сохранять текст, если включены история или синхронизация буфера.
- Временная WAV-запись удаляется после успеха, ошибки, отмены и штатного выхода. Принудительное завершение процесса или отключение питания может оставить временную запись в `%TEMP%`; удалите `macdictate-audio-*.wav` вручную при необходимости.
- Аудио и распознанный текст не отправляются по сети и не пишутся в диагностические логи. Интернет нужен только для явной загрузки модели и открытия страницы релизов.
- Windows 10 (2004+) / 11 x64 — целевая платформа. Сборка и native smoke в GitHub проверяются на **Windows Server 2025**; это не заменяет проверку физического микрофона, клавиш и вставки на Windows 10/11. Поддержка жизненного цикла самой Windows и .NET зависит от Microsoft.
- Инсталляция рядом с portable-копией допустима, но одновременно работает один экземпляр приложения на пользовательский сеанс. Обновляйте всю папку пакета: runtime и lock-файл входят в поставку.

## Сборка и проверки

Из корня desktop Git-репозитория (`macos/`):

```sh
dotnet run --project windows/tests/MacDictate.Core.Tests/MacDictate.Core.Tests.csproj
dotnet build windows/src/MacDictate.Windows/MacDictate.Windows.csproj
```

SDK закреплён в `windows/global.json`; из Windows-папки выполняются publish/package scripts. Cross-build на Mac проверяет компиляцию, но не исполняет Win32.

Native Windows интеграция:

```powershell
MacDictate.exe --smoke-test --report native-smoke.json
MacDictate.exe --transcribe sample.wav --model model.bin --language en --report asr-smoke.json
```

Запускайте WinExe через `Start-Process -Wait -PassThru` и проверяйте `ExitCode` и JSON-файл; полагаться на вывод в консоль не требуется. Native smoke открывает собственный TextBox, проверяет реальный Unicode-ввод, суррогатную пару и безопасную замену перевода строки пробелом с read-back, сохранность буфера обмена, закрытие активного native Alt-меню, запрет чужого окна и другого TextBox в том же окне с проверкой неизменности обоих полей, регистрацию hook/альтернативных клавиш и игнорирование injected Alt. Физический микрофон и физические нажатия Alt этим тестом не проверяются. `--transcribe` использует существующий файл, не удаляя переданный пользователем источник.

## Карта кода

- `src/MacDictate.Core`: pure hotkey policy, settings/last text store, pinned model downloader, bounded Whisper process runner.
- `src/MacDictate.Windows/Native`: WinMM event-driven capture с pinned buffers, keyboard hook, foreground/input-safe Unicode SendInput bridge и ограниченная по времени UI Automation identity. WPF framework reference нужен только для системного UI Automation API; интерфейс приложения остаётся WinForms.
- `src/MacDictate.Windows/TrayApplication.cs`: lifecycle и связка сценария диктовки; настройки и smoke выделены отдельно.
- `tests/MacDictate.Core.Tests`: console harness без test-framework зависимостей; реальные ошибки, отмена, timeout, integrity/atomic replacement.
- `runtime-lock.json`, `scripts/`: источник runtime/model pins и упаковка, принадлежат release-контуру.

## Восстановление после отдельных ошибок

Если доступность стороннего приложения зависла, автоввод безопасно отключается: последняя диктовка остаётся для ручного копирования. Перезапустите MacDictate, чтобы восстановить проверку фокуса. Файл модели с отличающимся SHA не перезаписывается: перенесите его в другое место и повторите загрузку, либо выберите существующую рабочую модель. Windows10 Home/Pro находится вне текущего официального списка поддержки .NET10; проверка совместимости на клиентской ОС остаётся отдельной.

Если SmartScreen показывает неизвестного издателя, сначала сравните SHA-256 файла с `WINDOWS-SHA256SUMS` из того же релиза (`Get-FileHash -LiteralPath "$env:USERPROFILE\Downloads\MacDictate_Windows_v1.6.0_x64.exe" -Algorithm SHA256`; замените путь в кавычках на путь к скачанному файлу). Если проверка совпала и вы доверяете источнику, Windows может предложить **More info → Run anyway**. При запрете политикой организации обратитесь к администратору; отключать защиту системы для установки не требуется.
