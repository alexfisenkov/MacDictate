# Индекс инженерного канона macOS

До этого индекса двенадцать файлов `macos/docs/*.md` различались только числовым
префиксом в имени — понять, какой файл нужен, можно было только открыв каждый.
Здесь — путь, что внутри, когда открывать и размер (`wc -l`/`wc -c`, снято 2026-09-10)
для всех двенадцати, плюс `legal/` и `superpowers/`. Числа строк актуализированы 2026-10-19. Пересверить — `wc -l <путь>`.

## Источники истины и порядок обновления

Все двенадцать файлов верхнего уровня — источники истины по своей теме для
macOS-продукта; `docs/*.md` в корне проекта их пересказывает и ссылается через
`source_of_truth`, а не дублирует.

**Два файла — журналы: `macos/docs/2_ActionLog.md` и `macos/docs/4_Decision_Log.md`.**
Их не переписывают и не сокращают — в них дописывают новую запись сверху или снизу
по уже принятому в файле порядку, старые записи остаются как есть. Остальные десять
файлов — живые документы: правятся на месте, когда факт устарел.

### Форматы записей

Как выглядит новая запись в каждом из живых логов канона — сверено с текстом самих
файлов, а не с описанием со стороны:

- **`macos/docs/4_Decision_Log.md`** — запись открывается заголовком
  `## D-NNN — <заголовок>` и несёт поля списком: `**Дата:**`, `**Решение:**`,
  `**Почему:**`, и опционально `**Ограничение:**`. Номер `D-NNN` не переиспользуется.
- **`macos/docs/2_ActionLog.md`** — запись открывается заголовком
  `## YYYY-MM-DD — <заголовок>` и содержит перечень шагов маркированным списком; на
  границе спринта или перед рискованным этапом последним пунктом идёт чекпойнт-тег,
  например `Чекпойнт: checkpoint/1.5.0-sprint2` — не у каждой записи, только у
  риск-этапов.
- **`macos/docs/3_TechDebt_Tasks.md`** — одна таблица со столбцами
  `Area | Status | Priority | Impact | Effort | Owner | Item`, без записей вне таблицы.

Раскладка `macos/docs/` своего отдельного скрипта проверки не имеет — её
частично проверяет общий `docs/проверить-раскладку.py` (корень проекта).
Потолок строк (правило 7) не распространяется ни на один файл `macos/docs/`,
включая этот индекс. Контракт frontmatter (правило 1), наоборот, распространяется
ровно на один файл — на сам `macos/docs/00-индекс.md`: у остальных двенадцати
файлов канона, `legal/` и `superpowers/` frontmatter не проверяется никак. Этот
индекс делит с `docs/00-индекс.md` ещё два правила: правило 4 — каждый путь,
названный здесь, существует на диске; правило 8 — число строк рядом с путём
совпадает с `wc -l`.

Этот индекс завёлся ровно затем, чтобы двенадцать файлов `macos/docs/*.md` перестали
различаться только числовым префиксом в имени — он обязан защищать сам себя, раз общий
скрипт сюда не заходит. **Новый файл `macos/docs/*.md` обязан получить строку в
соответствующей таблице этого индекса** (в «Двенадцать файлов верхнего уровня»,
`legal/` или `superpowers/` — по месту) тем же изменением, которое его создаёт.
Пропущенный файл здесь не найдёт ни правило 4 общего скрипта, ни следующая сессия.
