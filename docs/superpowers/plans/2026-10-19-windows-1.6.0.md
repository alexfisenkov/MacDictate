# Windows support and desktop 1.6.0 Implementation Plan

> **For agentic workers:** Use the existing project QA and independent critic-review. Checkboxes track deliverables; do not publish before final CI succeeds.

**Goal:** Ship a free Windows x64 tray dictation app, verify both desktop platforms through GitHub, publish desktop 1.6.0.

**Architecture:** Keep native Swift/AppKit macOS app. Add a native .NET WinForms Windows app under `windows/` in the existing desktop Git repository (physical root remains `macos/`). Platform-independent policy/process/model services are separate from Win32 audio, hotkey, paste and tray UI. No license or server dependency.

**Tech Stack:** .NET 10, WinForms, Win32 waveIn/keyboard hook/SendInput, pinned whisper.cpp CPU build, multilingual Whisper model.

**Spec:** This document records the current user request and design decisions; no separate speculative product spec.

## Global constraints

- User request: add Windows support, use GitHub checks and publish a new version.
- Owner chose **double Alt**; alternatives remain selectable in settings.
- Baseline Windows 10 (2004+) / 11 x64. Hosted CI uses Windows Server2025; Win10 physical acceptance must be reported separately, including .NET OS lifecycle limitations.
- Local speech recognition; audio/text never uploaded. Only model download and user-invoked release-page opening use the network.
- First Windows release implements dictation, language/model setup, recovered last text, safe paste and configurable hotkey. macOS optional LLM text correction is not claimed as Windows parity.
- No new public repository; preserve macOS/iOS/Transcribe sources and existing free behavior.
- Signed/notarized macOS DMG. Windows self-contained portable ZIP plus per-user installer if available; do not call unsigned Windows artifacts signed.
- Pin runtime source and model digest; retain upstream notices. Self-contained .NET runtime, no Python/Homebrew requirement on Windows.
- One final manual GitHub workflow on the complete source SHA, with targeted rerun only for an evidenced failure. Never publish on a failed/unknown CI result.

## Review focus

1. AltGr, Alt+Tab, key repeats and mixed keyboard shortcuts must not start dictation; hook must never swallow ordinary typing.
2. Focus changes and elevated apps must not receive unintended paste; recovered text remains accessible if paste cannot proceed.
3. Cancelled/failed model download must preserve a valid model; verify digest before atomic replace.
4. Recording, timeout and shutdown must release native buffers/processes and delete session audio; no audio/transcript logging.
5. Offline/missing model/microphone denied must show actionable recovery; no silent empty success.
