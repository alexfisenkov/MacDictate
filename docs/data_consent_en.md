# DATA PROCESSING FOR SUPPORT REQUESTS

Local use of the free MacDictate macOS application does not require sending personal data to the Operator or consenting to mailing lists. This document covers information the User voluntarily provides when contacting support.

## 1. PURPOSES OF PROCESSING
Contact details and the message provided are used to respond, diagnose the reported issue, and resolve questions about the Software or previous purchases. Subscribing to advertising is not a condition of support or use of the Software.

## 2. DATA PROVIDED
- Email address or another contact provided for a reply.
- The support message and voluntarily attached materials.
- Previous order details, where needed to resolve the User's question.

The free application does not request a Machine ID or payment details. Dictation audio and text remain on the device unless the User chooses to send them to support.

## 3. PROCESSING METHODS
Provided data may be processed using automated tools, including collection, recording, organization, storage, updating, retrieval, use, blocking, deletion, and destruction for the purpose of handling the request.

## 4. WITHDRAWAL AND DELETION
4.1. The User may contact the email address below to request that processing stop or that provided data be deleted.
4.2. Requests are handled with regard to applicable retention requirements for previous orders. Stopping processing does not restrict local use of the current free version of MacDictate.
4.3. Launching or downloading the free application does not by itself constitute consent to advertising messages.
