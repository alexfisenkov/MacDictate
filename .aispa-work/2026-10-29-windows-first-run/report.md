# MacDictate Windows 1.6.1 — исправление первого запуска

## Решения, принятые за тебя
- Сохранил Windows 10 build 19041+ / Windows 11 x64. Конфигурация компьютера друга неизвестна.
- Вместо скрытого трея открывается обычное окно настройки. Большая загрузка начинается по явному нажатию; проверенная модель сохраняется автоматически.
- Сохранил двойной левый Alt и добавил понятную кнопку записи. Windows-исправление не меняет macOS 1.6.0.

## Что изменено
Первый запуск ведёт от модели к микрофону, проверке клавиши и первой записи. На основном экране видны следующий шаг, состояние, ошибка, обработка и полученный текст с кнопкой копирования. После загрузки больше не нужно искать Save.

Можно выбрать микрофон, проверить сигнал, открыть нужные настройки Windows и повторить проверку. Программа объясняет, что у обычного desktop-приложения отдельного системного запроса разрешения может не быть.

Горячая клавиша обрабатывается отдельно от UI. Отмена проверяется перед началом захвата и отправкой текста. Сменившееся или неизвестное поле не получает автоматический ввод. Результат остаётся доступен для ручного копирования. Повторный запуск возвращает окно существующего процесса.

Изменены Windows-приложение и тесты, упаковка и CI, Windows-канал версий, сайт и релизные документы. Runtime macOS/iOS/Transcribe не менялся. Пользовательские CLAUDE.md/AGENTS.md не перезаписывались.

## Что нужно от тебя
Секретов, ключей, платных аккаунтов и незаполненных переменных нет. Кодовых заглушек нет.

Для подтверждения именно компьютера друга остаётся одна живая проверка: установить новый EXE и пройти модель → микрофон → первую запись. Если проблема останется, скопировать безопасную диагностику из приложения. Аудио, переписку и пароли отправлять не нужно. Без доступа к этому ПК я не выдаю его микрофон и физический Alt за проверенные.

## Что не вошло и что не проверено
Требования пользователя не отменялись. Автоматический Windows Server 2025 контур принят. Физические Windows 10/11: микрофон, Alt и внешний редактор — NOT_RUN. Реальный монитор 125/150%, GUI HTTP-success модели, интерактивный installer/SmartScreen отдельно не проверены. PCM и активация клавиши в сценарии явно синтетические; реальный ASR подтверждён отдельно.

Windows-пакет пока без цифровой подписи. Защита или политика организации могут блокировать запуск; отключать защиту не предлагается.

## Что пошло не по плану
1. После scoped review остались два обработчика локальных ошибок. Объявлено небольшое дополнительное исправление и одна локальная проверка, без третьего полного круга ревью.
2. Первый CI 40744090057: Windows прочитала UTF-8 реестр как cp1252. Исправлено явной кодировкой и регрессией.
3. Второй CI 40745192074: тест ошибочно требовал пустое поле результата до первой диктовки. Приёмка разделена на пустое и заполненное состояния; обязательный результат/Copy и фактическое копирование сохранены.
4. Третий CI 40747430459 прошёл. Неудачные попытки сохранены в истории.
5. Масштабирование 125/150% проверено контролируемым layout-stress и не выдано за физический DPI.

## Что осталось после ревью
Существующая модель с другим hash не перезаписывается: для восстановления нужно перенести файл или выбрать рабочую модель. Один populated installed PNG не попал в артефакт; UIA/clipboard-проверка прошла, отдельный real-ASR result PNG сохранён. Полный CI только ради этого PNG не повторялся.
