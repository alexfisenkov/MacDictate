# Приёмка первого запуска

- Чистый профиль: окно видно без поиска трея; модель не готова, следующее действие понятно.
- Модель: один явный запуск скачивания, прогресс/объём/отмена; успех сразу сохранён, рестарт не требует Save.
- Нет устройства или отказ capture: понятный экран, privacy/input settings, retry; нельзя ложно объявить рабочий микрофон.
- Реальный mic-тест на клиенте: 5с записи и сигнал, правильный выбранный вход. На CI synthetic seam помечен отдельно.
- Alt: проверка показывает отклик, двойной левый старт/стоп; AltGr/комбинации не запускают. Thread pump не блокируется UI.
- Кнопка записи: работает как запасной путь; видны запись, остановка, обработка, отмена и результат.
- Сквозной UI CI: controlledPCM/fixture→реальный bundledWhisper→видимый текст→Copy, один тяжёлый вызов. Report не называет synthetic microphone физическим.
- Глобальный ввод: сменившееся поле не получает текст; результат виден/копируется, буфер не потерян.
- Выход/повторный запуск/обновление: окно поднимается, настройки и модель сохраняются, нет второго конфликтующего процесса.
- Сайт: EXE primary, ZIP secondary; подпись/Windows-only pinned link/first steps понятны на RU/EN и телефоне.
- Выпуск: Windows1.6.1 не смещает global latestMac1.6.0; sourceSHA/hash/installer/installed-copy подтверждены.
