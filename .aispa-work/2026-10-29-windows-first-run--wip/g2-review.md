# G2 — независимая проверка покрытия

Проверяющий windows_g2_coverage получил только дословный бриф и спецификацию, без manifest/интерфейсов/кода. Результат PASS: отсутствующих/наполовину покрытых/самостоятельных требований не найдено. PASS означает покрытие спецификацией, не доказательство работы программы. Внешняя физическая проверка Windows остаётся явно названной границей приёмки.
