# 01 — От первого запуска к первой диктовке

**Требования:** R01, R03, R04, R05, R06, R07, R08i, R09i, R10i
**Зависит от:** —
**Зона:** `windows/src` · `windows/tests` · `windows/scripts/check-local.sh` · `scripts/check_architecture_guardrails.sh`
**Волна:** 1
**Ревью:** да — фундамент
**Модель:** сильная

## Что должно заработать
Видимое основное окно/setup, проверенная автоматически сохранённая модель, выбор/тест микрофона с уровнем, понятная диагностика разрешений, независимый keyboard message-loop и видимая проверка двойного левого Alt. Первый пользователь получает текст и Copy, а не ищет скрытые настройки/Save/трей. Не добавлять runtime зависимости.

## Из брифа, дословно
> «после установки ни каких разрешений не выскакивает»
> «ничего в итоге не работает при нажатии на альт»
> «никаких инструкций что куда нажать? Никаких автоматических действий, и ни какой работы в итоге!»

## Разделы спецификации
Задача; Решение; Истории R01, R03–R10i со всеми производными; Решения по реализации; Открытые внешние проверки. interfaces.md и notes.md.

## Критерии приёмки
- [ ] Fresh launch показывает DPI-friendly RU/EN основной экран с готовностью и одним следующим действием; нет скрытого Save после model download; persisted old settings читаются.
- [ ] Есть выбор входа, явная короткая реальная запись/уровень, отсутствие устройства/ошибка/тишина не становятся ложной зелёной готовностью; открытие Windows privacy/settings + повторная проверка.
- [ ] Двойной левый Alt видимо проверяется во время setup и запускает/останавливает dictation при readiness; dedicated message-loop hook не зависит от UI, AltGr/chords/injected не записывают.
- [ ] Видимая запись/stop/cancel/processing/result/manualCopy, глобальный ввод сохраняет FocusIdentity guard; Home-origin не печатает в собственную форму. Повторный запуск поднимает окно существующего процесса.
- [ ] Offline/отмена/hash/missingruntime/badmodel/noinput/writefailure понятны и восстановимы; модели/пользовательские исходники сохраняются, тестовое аудио удаляется, диагностика без содержания голоса/текста.
- [ ] Новый check-local проходит, новые реальные regression tests имеют REDPROOF, существующие тесты не ослаблены. --onboarding-smoke --report PATH использует isolated test profile, отчёт явно маркирует synthetic seams и real device probes; normal production mode нельзя сделать готовым fake env flags.
- [ ] Разрешить только .aispa-work/* в существующем architecture whitelist как активную metadata-зону; остальные guardrails сохранить. Это первая интеграционная правка перед остальным кодом.
