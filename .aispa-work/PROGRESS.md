# MacDictate Windows — что осталось

Последняя сборка: Windows 1.6.1 first-run; source56b45301, CI40747430459. Релиз, публичный EXE и сайт подтверждены. Материалы: .aispa-work/2026-10-29-windows-first-run/.

## Договорились — не пересматривать
- «Сам по брифу» / «Сбалансированно» для этого прогона.
- Windows-only исправление не смещает global latest Mac 1.6.0.
- Синтетические PCM и активация клавиши не выдаются за физическую приёмку.

## Не доделано
- R03/R04/R07: физический Windows 10/11 и компьютер друга недоступны. Проверить модель → микрофон → двойной Alt → внешний редактор; при сбое взять только безопасную диагностику.
- Нативные мониторы DPI125/150%, GUI HTTP-success модели и интерактивный SmartScreen отдельно не проверены. Автоматический layout-stress явно помечен как synthetic.

## Известные баги и ограничения
- Файл модели с другим hash сохраняется; повторное скачивание само его не ремонтирует. Нужен перенос или выбор рабочей модели.
- Один populated installed PNG не сохранился в артефакте. UIA/clipboard прошли, отдельный real-ASR result PNG сохранён; поправить имя/retention при следующей проверке.
- Windows пока unsigned; не обходить политику безопасности. Для Authenticode нужен отдельный план.
