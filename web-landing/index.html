Скачайте и начните диктовать

Windows 10 / 11 x64

Рекомендуем установщик EXE. Он добавит MacDictate в меню «Пуск» и откроет окно первой настройки.

Скачать установщик EXE · Windows 10/11 x64

1. Скачайте EXE, запустите его и завершите установку. Оставьте включённым «Запустить MacDictate»: откроется основное окно. Позже откройте программу из меню «Пуск».

2. Нажмите «Начать настройку: скачать модель» (~488 МБ). Дождитесь проверки и автоматического сохранения. Затем распознавание работает без сети.

3. Выберите микрофон и нажмите «Проверить микрофон». Говорите 3 секунды и следите за уровнем. Если сигнала нет, откройте «Доступ к микрофону в Windows», разрешите доступ классическим приложениям и повторите тест. Отдельного запроса Windows обычно нет.

4. Нажмите «Начать запись», произнесите фразу и нажмите «Остановить и распознать». Дождитесь текста в окне и нажмите «Копировать текст». Кнопка работает независимо от Alt.

5. Для диктовки в другое приложение проверьте клавишу, затем поставьте курсор в текстовое поле. Два быстрых нажатия левого Alt начинают запись; ещё два останавливают. Правый Alt/AltGr не подходит. Максимум — 2 минуты; если автопечать не сработала, скопируйте текст в окне MacDictate.

Закрытие окна оставляет MacDictate в трее. Двойной щелчок по его значку или повторный запуск из «Пуска» снова покажет окно.

Portable ZIP · без установки

ZIP — дополнительный вариант для запуска без установки: распакуйте всю папку и откройте MacDictate.exe. Не запускайте EXE прямо из архива и сохраняйте папку runtime рядом с ним.

Portable ZIP · без установки

Windows-пакет без цифровой подписи: Windows может предупредить или заблокировать запуск. Проверьте источник — официальный GitHub Release; при необходимости сверьте SHA-256 из WINDOWS-SHA256SUMS. Если доступно, выберите «Подробнее» → «Выполнить в любом случае» только после проверки. Если политика компьютера запрещает запуск, обратитесь к администратору. Не отключайте защиту Windows. Проверки на Windows Server 2025 и синтетическое аудио не подтверждают работу физического микрофона и Alt на Windows 10/11. Windows 10 Home/Pro вне официального срока поддержки .NET 10. Дополнительной модели улучшения текста в Windows пока нет.

При ошибке нажмите в окне «Копировать диагностику без личных данных» и отправьте этот текст в поддержку. Аудио, диктовку, пароли и снимки чужой переписки отправлять не нужно.

macOS · Apple Silicon

Установите MacDictate на Mac с Apple Silicon. При первом запуске загрузите модель Whisper и разрешите доступ к микрофону и «Универсальному доступу». Дважды нажмите Option для начала записи и один раз — для завершения.
