Пошаговая настройка Windows 10 / 11 →

1. Скачайте EXE, запустите его и завершите установку. Оставьте включённым «Запустить MacDictate»: откроется основное окно. Позже откройте программу из меню «Пуск».

2. Нажмите «Начать настройку: скачать модель» (~488 МБ). Дождитесь проверки и автоматического сохранения. Затем распознавание работает без сети.

3. Выберите микрофон и нажмите «Проверить микрофон». Говорите 3 секунды и следите за уровнем. Если сигнала нет, откройте «Доступ к микрофону в Windows», разрешите доступ классическим приложениям и повторите тест. Отдельного запроса Windows обычно нет.

4. Нажмите «Начать запись», произнесите фразу и нажмите «Остановить и распознать». Дождитесь текста в окне и нажмите «Копировать текст». Кнопка работает независимо от Alt.

5. Для диктовки в другое приложение проверьте клавишу, затем поставьте курсор в текстовое поле. Два быстрых нажатия левого Alt начинают запись; ещё два останавливают. Правый Alt/AltGr не подходит. Максимум — 2 минуты; если автопечать не сработала, скопируйте текст в окне MacDictate.

Настройка Windows: от микрофона до первого текста

Отдельного окна с запросом разрешения может не быть — для классической программы это нормально. Настройте доступ по шагам ниже. В приложении эту инструкцию можно открыть кнопкой «Пошаговая настройка Windows», в том числе без интернета.

1. Разрешите микрофон — выберите вашу версию Windows

Не знаете версию? Откройте «Пуск → Параметры → Система → О системе» и найдите «Характеристики Windows». Затем раскройте подходящий раздел ниже.

Windows 11 — куда зайти и что включить
  1. В MacDictate нажмите «Доступ к микрофону в Windows». Если настройки не открылись, нажмите Win+I или «Пуск → Параметры», затем «Конфиденциальность и безопасность → Микрофон».
  2. Включите «Доступ к микрофону».
  3. Включите «Разрешить приложениям доступ к микрофону».
  4. Прокрутите ниже и включите «Разрешить классическим приложениям доступ к микрофону». Этот переключатель относится к классическим программам в целом.
Windows 10 — куда зайти и что включить
  1. В MacDictate нажмите «Доступ к микрофону в Windows». Если настройки не открылись, нажмите Win+I или «Пуск → Параметры», затем «Конфиденциальность → Микрофон».
  2. Под надписью «Доступ к микрофону для этого устройства» нажмите «Изменить» и включите доступ. Если он уже включён, переходите дальше.
  3. Включите «Разрешить приложениям доступ к микрофону».
  4. Прокрутите страницу вниз и включите «Разрешить классическим приложениям доступ к микрофону». Этот переключатель относится к классическим программам в целом.

MacDictate может отсутствовать в списке отдельных приложений: искать его там не нужно. Важно разрешение для классических приложений. Названия пунктов могут немного отличаться в разных обновлениях Windows. Если переключатель серый или настройками управляет организация, попросите администратора разрешить доступ; переустановка программы этот запрет не снимает.

2. Выберите микрофон и проверьте сигнал
  1. Подключите микрофон или гарнитуру. Для Bluetooth дождитесь подключения. Проверьте кнопку выключения микрофона на гарнитуре и клавиатуре: звук не должен быть отключён.
  2. В MacDictate нажмите «Настройки звука». Если окно не открылось, нажмите Win+I и выберите «Система → Звук». Далее используйте шаг для вашей версии Windows.
  3. Windows 11: в разделе «Ввод» выберите нужный микрофон и откройте его свойства. Найдите «Проверка микрофона», нажмите «Начать тест», произнесите фразу и нажмите «Остановить тест». Проверьте результат; при необходимости увеличьте громкость входа.
  4. Windows 10: в разделе «Ввод» выберите нужный микрофон. Произнесите фразу и посмотрите на индикатор «Проверьте микрофон»: он должен реагировать на голос. При необходимости увеличьте громкость входа в свойствах устройства.
  5. Вернитесь в MacDictate, нажмите «Обновить входы» и выберите тот же микрофон в списке. Нажмите «Проверить микрофон» и говорите 3 секунды. Уровень должен двигаться, а после теста появится сообщение «Сигнал получен в этом сеансе. Можно записывать».
  6. Если устройств нет, переподключите микрофон и снова нажмите «Обновить входы». Если проверка Windows тоже не получает звук, проверьте подключение, выбранный вход и mute; при необходимости обратитесь за помощью с устройством или драйвером. Если Windows получает звук, а MacDictate — нет, ещё раз проверьте доступ классическим приложениям и повторите тест в программе.
3. Получите первый текст кнопкой
  1. Если модель ещё не загружена, нажмите «Начать настройку: скачать модель» (~488 МБ) и дождитесь окончания. Модель сохраняется автоматически. Интернет нужен для этой загрузки, а не для последующей диктовки.
  2. Нажмите «Начать запись», произнесите короткую фразу, затем «Остановить и распознать». Дождитесь появления текста. Во время распознавания не начинайте новую запись; для отмены есть кнопка «Отменить».
  3. Нажмите «Копировать текст», откройте Блокнот или другой редактор, щёлкните в поле текста и нажмите Ctrl+V. Появившийся текст подтверждает, что запись и распознавание прошли.
4. Настройте двойной левый Alt
  1. В списке горячих клавиш выберите DoubleAlt, затем нажмите «Проверить клавишу без записи». Дважды быстро нажмите и отпустите левый Alt, не удерживая его. Дождитесь подтверждения и нажмите «Завершить проверку клавиши». Отдельного разрешения Windows на эту клавишу не требуется.
  2. Поставьте курсор в текстовое поле другого приложения. Два быстрых нажатия левого Alt начинают запись, ещё два — останавливают. Правый Alt/AltGr и сочетания вроде Alt+Tab не подходят. Оставьте исходное поле активным до результата.
  3. Если Alt не определяется, выберите в списке F8 или CtrlShiftSpace (Ctrl+Shift+Пробел), проверьте выбранную клавишу и завершите тест. Нажатие выбранной клавиши начинает запись, повторное — останавливает. Кнопка «Начать запись» тоже остаётся доступной.
  4. Если текст не вставился автоматически, откройте окно MacDictate, нажмите «Копировать текст» и вставьте его вручную через Ctrl+V. Если часть текста уже появилась, проверьте её перед повторной вставкой. Для открытия окна дважды щёлкните значок MacDictate у часов (он может быть под стрелкой скрытых значков) или снова запустите программу из «Пуска».

Portable ZIP · без установки

ZIP — дополнительный вариант для запуска без установки: распакуйте всю папку и откройте MacDictate.exe. Не запускайте EXE прямо из архива и сохраняйте папку runtime рядом с ним.

Windows-пакет без цифровой подписи: Windows может предупредить или заблокировать запуск. Проверьте источник — официальный GitHub Release; при необходимости сверьте SHA-256 из WINDOWS-SHA256SUMS. Если доступно, выберите «Подробнее» → «Выполнить в любом случае» только после проверки. Если политика компьютера запрещает запуск, обратитесь к администратору. Не отключайте защиту Windows. Проверки на Windows Server 2025 и синтетическое аудио не подтверждают работу физического микрофона и Alt на Windows 10/11. Windows 10 Home/Pro вне официального срока поддержки .NET 10. Дополнительной модели улучшения текста в Windows пока нет.

При ошибке нажмите в окне «Копировать диагностику без личных данных» и отправьте этот текст в поддержку. Аудио, диктовку, пароли и снимки чужой переписки отправлять не нужно.
